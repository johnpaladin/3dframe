# 3D 視窗相框

用手機前鏡頭追蹤眼睛位置,即時改變螢幕裡的透視,讓手機螢幕看起來像一扇通往裡面空間的「窗戶」。

## 原理

1. **眼部追蹤**:用 [MediaPipe Face Landmarker](https://developers.google.com/mediapipe/solutions/vision/face_landmarker) 取得兩眼虹膜中心。
2. **估算 3D 位置**:兩眼在畫面上的像素距離,加上平均瞳距(約 6.3 cm)和相機焦距,可以算出眼睛到螢幕的距離 `z`,再推出左右 `x`、上下 `y`(單位都是公分)。
3. **非對稱視錐投影(off-axis projection)**:把螢幕當成位在 `z = 0` 的實體矩形,從眼睛位置穿過螢幕四個角建立投影矩陣。這不是單純「移動物體」,而是重現你從那個位置透過窗戶看進去會看到的畫面,所以錯覺很真實。
4. 用 One Euro 濾波器降低抖動,同時維持反應速度。

## 場景

- **房間**:經典的格線盒子加上懸吊的球,還有一個凸出螢幕外的物體
- **山景**:多層山脈剪影、月亮和螢火蟲
- **照片**:把你自己的照片放進有深度的相框(在「照片」上再點一次就能選照片)

## 使用方式

純靜態網頁,不需要建置。**相機只能在 HTTPS(或 localhost)下使用。**

本機測試:

```bash
npx serve .            # 或 python3 -m http.server
# 電腦瀏覽器開 http://localhost:3000
```

用手機測試時要有 HTTPS,最簡單的方法:

- **GitHub Pages**:repo 的 Settings → Pages → Branch 選 `main` / root,幾分鐘後用 `https://<帳號>.github.io/3dframe/` 開啟
- 或用 `npx localtunnel --port 3000`、`ngrok http 3000` 這類工具產生 HTTPS 網址

## 校正(讓效果更準)

打開右上角 ⚙︎:

- **螢幕短邊寬度**:量一下手機螢幕短邊的實際寬度(cm)
- **校正距離**:把手機拿在離眼睛約 30 cm 處按下按鈕,會自動算出相機視角
- **效果強度**:大於 1 會放大位移,效果比較誇張
- **景深**:場景往螢幕內延伸多深

小技巧:這是「單眼」透視,**閉上一隻眼睛**看會最立體。

## 沒有相機時

可以選「不用相機」:手機用陀螺儀(轉動手機),電腦用滑鼠移動。
